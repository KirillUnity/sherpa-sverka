# Промт 01. Каркас папки и учебные строки

Ты собираешь первую версию проекта сверки в Sherpa. Пользователь ещё не запускает сверку: он должен увидеть понятную папку, учебные файлы и инструкцию, куда класть выгрузку и отчёт.

Робот называется «Сверка двух таблиц». Пользователь кладёт в одну папку выгрузку и отчёт, позже запускает робота в Sherpa на своём компьютере и получает файл расхождений. Письма никуда не уходят. Чужие системы робот не открывает.

Оркестратор, очереди задач и распознавание документов задуманы, ещё нет. Кода робота в папке пока нет. Блоки Sherpa не выдумывай: имена блоков Designer в этот пункт не входят.

## Что уже есть

Есть только задание `TZ.md`. Папки `robot/`, `samples/` и `README.md` ещё нет.

## Что сделать в этом пункте

Собери каркас так, чтобы человек без репозитория понял, какие два файла класть и какой результат ждать.

Учебная выгрузка:

- 101 / 1000 / оплачен
- 102 / 500 / оплачен
- 103 / 200 / новый

Учебный отчёт:

- 101 / 1000 / оплачен
- 102 / 450 / оплачен
- 104 / 300 / оплачен

Ожидание после будущего прогона: четыре разных номера, три расхождения. Номер 102 с разными суммами. Номер 103 только в выгрузке. Номер 104 только в отчёте. Номера 101 в расхождениях нет.

Робот в этом пункте ещё ничего не сверяет и файлы расхождений не пишет.

## Чего не делать

Не открывать почту и чужие системы. Не придумывать оркестратор, очереди и распознавание. Не изобретать имена блоков Sherpa Designer. Не реализовывать сверку, проверку наличия файлов и запись результата.

## Сценарий проверки

1. Открыть папку проекта и найти учебную выгрузку, учебный отчёт и ожидаемый файл расхождений.
2. Открыть инструкцию и увидеть, куда положить два файла и как называется робот.
3. Убедиться, что диаграмма робота ещё не считает расхождения.

# Техническое приложение

## Файлы

| Путь | Зачем |
| --- | --- |
| `TZ.md` | Задание, не переписывать |
| `robot/sverka.sherpa` | Пустой проект Sherpa Designer |
| `robot/sverka.process` | Диаграмма: пока только запуск, без сверки |
| `samples/vigruzka.csv` | Учебная выгрузка |
| `samples/otchet.csv` | Учебный отчёт |
| `samples/expected-rashozhdeniya.csv` | Ожидаемый результат будущего прогона |
| `README.md` | Куда положить файлы и как запустить робота |

Имена во рабочей папке пользователя: `vigruzka.csv`, `otchet.csv`. Результат позже: `rashozhdeniya.csv`. Ошибка отсутствия файла позже: `oshibka.txt`.

Рабочая папка читается из переменной `Papka`.

## Методы и параметры

Колонки обоих входов: `nomer`, `summa`, `status`.

Колонки ожидаемого результата:

| Поле | Смысл |
| --- | --- |
| `tip` | `summa`, `status`, `net-v-otchete`, `net-v-vigruzke` |
| `nomer` | номер строки |
| `summa_vigruzka` | сумма из выгрузки или пусто |
| `summa_otchet` | сумма из отчёта или пусто |
| `status_vigruzka` | статус из выгрузки или пусто |
| `status_otchet` | статус из отчёта или пусто |

Формат всех CSV: UTF-8, разделитель запятая. Сумма без лишних нулей после запятой. Внутри группы строки по `nomer` как по тексту.

`samples/expected-rashozhdeniya.csv` должен совпасть построчно с:

```csv
nomerov,4
rashozhdeniy,3
tip,nomer,summa_vigruzka,summa_otchet,status_vigruzka,status_otchet
summa,102,500,450,оплачен,оплачен
net-v-otchete,103,200,,новый,
net-v-vigruzke,104,,300,,оплачен
```

В `README.md` указать:

- робот «Сверка двух таблиц»
- положить в `Papka` файлы `vigruzka.csv` и `otchet.csv`
- результат `rashozhdeniya.csv`, ошибка `oshibka.txt`
- Sherpa Designer ставится без лицензии; чтобы прогнать робота, нужна лицензия Sherpa Assistant
- курс: https://sherparpa.ru/besplatnyj-bazovyj-kurs/
- дистрибутив Windows: https://docs.sherparpa.ru/ssylki-na-distributivy/distributivy-sherpa-rpa-windows
- документация: https://docs.sherparpa.ru/sherpa-rpa

## Критерий готовности

В репозитории есть все пути из таблицы «Файлы». Учебные CSV и ожидаемый результат совпадают с контрактом. `README.md` объясняет имена файлов и запуск. Диаграмма не пишет `rashozhdeniya.csv` и `oshibka.txt`.
